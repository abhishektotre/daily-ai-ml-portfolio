## 📌 Overview
Production-grade analytical pipeline for **Network Intrusion & Anomaly Classification with Isolation Forest (Advanced Iteration 2)** in the **Machine Learning** domain.
Features robust synthetic telemetry generation, feature engineering, statistical modeling, and automated diagnostic evaluation.

### Key Capabilities
- Automated synthetic dataset generation with domain-tailored feature distributions and noise components.
- Scalable feature transformation, standard normalization, and cross-validation splitting.
- Tuned predictive classification/regression engine with comprehensive performance evaluation.
- Diagnostic artifact generation including evaluation plots and serialized metrics (`metrics.json`).
